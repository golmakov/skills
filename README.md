# Skills For Agents

Agent skills that I use. Most are reworked from other people.

## Skills

- [`ask-cc`](skills/ask-claude/SKILL.md) — Ask Claude Code for a judgment call on an ambiguous architecture, design, naming, or writing decision.
- [`changelog`](skills/changelog/SKILL.md) — Add a concise, user-facing entry to `CHANGELOG.md` for work that has landed.
- [`domain-modeling`](skills/domain-modelling/SKILL.md) — Build and sharpen a project's domain model while discussing terminology, issues, and design decisions.
- [`explain-diff-html`](skills/explain-diff/SKILL.md) — Create a rich, interactive HTML explanation of a code change, diff, branch, or pull request.
- [`grilling`](skills/grill/SKILL.md) — Stress-test a plan or design through a focused, one-question-at-a-time interview.
- [`implement`](skills/implement/SKILL.md) — Implement work described in a PRD or set of issues, with regular typechecking and testing.
- [`to-issues`](skills/to-issues/SKILL.md) — Break a plan, specification, or PRD into independently deliverable vertical-slice issues.
